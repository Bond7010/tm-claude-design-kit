# Prompt: FTH Homepage

Use this prompt to generate or update a Free Toast Host (FTH) homepage.

---

## Prompt template

```
Build a brand-compliant FTH homepage for [CLUB NAME].

Club details:
- Club number: [NUMBER]
- Meeting day/time: [e.g., "Every Tuesday at 7:00 PM"]
- Location: [VENUE or "Online via Zoom — link shared with members"]
- Area / Division / District: [e.g., "Area 12, Division C, District 96"]
- Club focus (optional): [e.g., "Corporate professionals", "Spanish-speaking members"]
- Contact email: [EMAIL]
- Social links (optional): [Facebook URL, etc.]

Brand requirements:
- Self-contained HTML with embedded CSS (no external dependencies)
- Colors: Loyal Blue #004165, True Maroon #772432, Cool Gray #A9B2B1, Happy Yellow #F2DF74
- Google Fonts: Montserrat (headlines) + Source Sans 3 (body) via @import
- Logo: use white version from asset-manifest.json on Loyal Blue header
- Responsive layout (mobile-first)
- One approved phrase as the hero tagline: [choose from approved-phrases.json]
- Include sections: hero, about, meeting info, contact/CTA
```
