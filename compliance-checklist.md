# Toastmasters Brand Compliance Checklist

Use this before finalizing any design. Source: Brand Manual v2.0 / 2025–2026.

---

## Colors
- [ ] All colors come from the approved palette: Loyal Blue, True Maroon, Cool Gray, Happy Yellow, White, Black
- [ ] Logo is not placed on any non-brand color
- [ ] Text on dark backgrounds uses White or Happy Yellow only
- [ ] Text on light backgrounds uses Loyal Blue, True Maroon, or Black only
- [ ] Happy Yellow used sparingly as accent — not as a dominant background

## Logo
- [ ] Logo is unaltered (no color changes, no distortion, no skewing)
- [ ] Clear space maintained (equal to full wordmark height on all sides)
- [ ] Logo is at least 72px wide (web) or ¾ inch (print)
- [ ] No text, symbols, or images overlap the logo
- [ ] No glow, pattern, or drop shadow behind the logo
- [ ] Logo is not placed on a face or the primary subject of a photo
- [ ] No custom club logo or tagline created

## Typography
- [ ] Headlines use Montserrat (or Gotham) — no word art, no drop shadows
- [ ] Body copy uses Source Sans 3 or Myriad Pro
- [ ] No typeface manipulation (warping, stretching, outline effects)
- [ ] Script fonts (Corinthia, Luxurious Script) reserved for special events only

## Copy & Phrases
- [ ] Only approved phrases used (see approved-phrases.json)
- [ ] No more than one approved phrase per piece
- [ ] "Communicate Confidently®" includes the registered trademark symbol
- [ ] No custom taglines or slogans invented for the club

## Photography
- [ ] Images show people giving speeches, engaged groups, professional meetings
- [ ] No landscapes, animals, children as primary subject
- [ ] No food, kitchen appliances, medicine, or architecture as sole focus
- [ ] No clip art or cartoons as primary design element
- [ ] Written permission obtained for all photos used
- [ ] No trademarked/copyrighted images used without written authorization
- [ ] Text never covers faces

## Clubs Specifically
- [ ] No locally produced banners, ribbons, or pins (require central approval)
- [ ] No sharing or forwarding of brand assets outside of approved club use
